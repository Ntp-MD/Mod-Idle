# The gates — every id in `tools/check.ts`

`tools/check.ts` is the engine cage. It prints one line per gate: the id, the state, and what the gate just
held. Every line below is read off that output, so the listing cannot drift from the code — refresh it from
`node tools/check.ts --checks` rather than editing a line by hand.

`PASS` is a gate that held, `PENDING` a watch read by eye (it never fails the run), `FAIL` a condition that broke.
