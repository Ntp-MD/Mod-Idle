# Animation atlas art reference kit

เริ่มอ่านไฟล์นี้ก่อนส่งงานให้ agent เจนภาพแอนิเมชัน (character/monster sprite
atlas) โฟลเดอร์นี้เป็นแม่แบบอ้างอิงชุดเดียวสำหรับมุมกล้อง 3/4 top-down, โครงสร้าง
กริด atlas, การเรียงทิศทาง 8 ทิศ, และ clip phases มุมกล้องมาจากโค้ดจริง ไม่ใช่การเดา
จาก screenshot

ภาพที่ generate ทุกไฟล์เก็บไว้ใต้ `outputs/` เพื่อรอ approve ก่อนนำไปใช้จริง
ห้ามคัดลอกเข้า `game/public/` หรืออ้างในโค้ดจนกว่าจะอนุมัติ

## เริ่มใช้งาน

1. อ่าน [base-prompt.md](base-prompt.md) — เป็นเทมเพลตเดียวสำหรับงาน atlas แอนิเมชัน
2. เลือกชุด pose ที่ต้องการ: locomotion (idle/walk/turn), action
   (windup/release/recovery), outcome (hit/death) ตาม `docs/animation.md`
3. กำหนดกริดและขนาดเซลล์ตามเป้าหมาย (ดูตัวอย่าง `art-reference/monsters/beast/harpy/animation/meta.json`)
4. ตรวจผลตามหัวข้อ Verification ใน base prompt แล้วลองวางในเกมก่อนทำชุดถัดไป

## สัญญากล้อง (จาก `game/src/presentation/arena-camera.ts`)

**Agreed camera: 3/4 top-down 45.92°** (ช่วง ~45–55°) — ค่าที่ตกลงใช้สำหรับงานชุดนี้

| ค่า                         | ตัวเลข                                         |
| --------------------------- | ---------------------------------------------- |
| Effective elevation         | 45.92° (3/4 top-down ~45–55°)                  |
| เมทริกซ์ฉาย M               | [[137.5274, 32.7446], [−26.1957, 98.2339]]     |
| การบีบแกน Y (เฉพาะฐาน/เท้า) | 0.718 ของแกน X                                 |
| วงรีเท้าแตะพื้น             | minor/major = 0.7183, แกนเอกเอียง 11.75°       |
| 8 ทิศ                       | S SE E NE N NW W SW (ตามเข็ม, ใต้ก่อน)         |
| จุดศูนย์กลาง sector (world) | 14.93°, 68.20°, 103.39°, 319.64° (ไม่สม่ำเสมอ) |

**จุดต่างจาก skill VFX:** ตัวละครเป็น **upright sprite** — ตัวยืนตรง เห็นหัว/ไหล่
จากด้านบน มีเพียงฐาน/เท้าที่แตะระนาบพื้นและผิดรูปตาม projection ไม่ใช่ footprint
ทั้งตัวแบบสกิล

## มีอะไรอยู่ที่ไหน

| ไฟล์/โฟลเดอร์    | หน้าที่                                             |
| ---------------- | --------------------------------------------------- |
| `base-prompt.md` | เทมเพลต prompt เดียวสำหรับเจนภาพ atlas แอนิเมชัน    |
| `outputs/`       | ที่เก็บผลงานใหม่แบบมีเลขรุ่น; ยังไม่ใช่การนำเข้าเกม |

## Clip phases (จาก `game/src/ui/combat/animation/manifest.ts`)

- **locomotion**: `idle`, `walk`, `turn`
- **action**: `windup`, `release`, `recovery`
- **outcome**: `hit`, `death`
- เพิ่มเติม: `channel`, `despawn`

## ข้อควรระวัง

- **มุมมองของตัวละคร ≠ การบีบพื้น** ตัวละคร upright ยืนตรง มุมกล้องเห็นหัว/ไหล่
  เท่านั้น การบีบ 0.718 ใช้กับฐาน/เท้าที่แตะพื้น ไม่ใช่ทั้งตัว
- **ทิศทางต้องเป็น silhouette ที่ต่างกันจริง** ไม่ใช่การหมุน/สะท้อนภาพเดียว
- **จุดยึดเท้าต้องอยู่ y = 0** (เมตร) และแนวสัมผัสพื้นคงที่ตลอดทุกเฟรม ตาม
  `docs/animation.md`
- ตาม [../map/README.md](../map/README.md) อย่ากำหนดองศาจาก screenshot หรือ
  คัดลอกค่าด้วยมือ ใช้ค่าที่ refresh จากโค้ดจริงเท่านั้น
