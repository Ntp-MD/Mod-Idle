# Skill VFX art reference kit

เริ่มอ่านไฟล์นี้ก่อนส่งงานให้ agent เจนภาพสกิล VFX โฟลเดอร์นี้เป็นแม่แบบอ้างอิง
ชุดเดียวสำหรับมุมกล้อง arena, วิธีนิยามรูปทรงพื้นที่ (cone/line/circle) และการตรวจ
คุณภาพ มุมกล้องมาจากโค้ดจริง ไม่ใช่การเดาจาก screenshot

ภาพที่ generate ทุกไฟล์เก็บไว้ใต้ `outputs/` เพื่อรอ approve ก่อนนำไปใช้จริง
ห้ามคัดลอกเข้า `game/public/` หรืออ้างในโค้ดจนกว่าจะอนุมัติ

## เริ่มใช้งาน

1. อ่าน [base-prompt.md](base-prompt.md) — เป็นเทมเพลตเดียวที่ใช้กับงานสกิล VFX
2. เลือกประเภทงาน: **cone**, **line**, หรือ **circle** ห้ามสลับประเภท
3. กรอกค่าจากแถวสกิลจริงใน `tools/data/skills.json` (`area.shape`,
   `area.angle_deg`, `area.length_m` / `area.width_m`) และทิศทางจาก
   `engine/skill-area.ts`
4. ตรวจผลตามหัวข้อ Verification ใน base prompt แล้วลองวางในเกมก่อนทำชุดถัดไป

## สัญญากล้อง (จาก `game/src/presentation/arena-camera.ts`)

**Agreed camera: 3/4 top-down 45.92°** (ช่วง ~45–55°) — ค่าที่ตกลงใช้สำหรับงานชุดนี้

| ค่า                 | ตัวเลข                                     |
| ------------------- | ------------------------------------------ |
| Effective elevation | 45.92° (3/4 top-down ~45–55°)              |
| เมทริกซ์ฉาย M       | [[137.5274, 32.7446], [−26.1957, 98.2339]] |
| การบีบแกน Y         | 0.718 ของแกน X                             |
| วงกลมบนพื้นเป็นวงรี | minor/major = 0.7183, แกนเอกเอียง 11.75°   |
| ทิศ East บนจอ       | −10.78°                                    |
| ทิศ North บนจอ      | +71.57°                                    |
| มุม East↔North บนจอ | 82.35° (ไม่ใช่ 90° — ไม่คงมุม)             |
| กรวย 90° ชี้ East   | 72.8°                                      |
| กรวย 90° ชี้ North  | 107.2°                                     |

**อย่าแก้ตัวเลขในส่วน CAMERA/PROJECTION ของ base prompt** ถ้า renderer เปลี่ยน
ให้วัดค่าจาก `arena-camera.ts` ใหม่ก่อน

## มีอะไรอยู่ที่ไหน

| ไฟล์/โฟลเดอร์    | หน้าที่                                             |
| ---------------- | --------------------------------------------------- |
| `base-prompt.md` | เทมเพลต prompt เดียวสำหรับเจนภาพสกิล VFX            |
| `outputs/`       | ที่เก็บผลงานใหม่แบบมีเลขรุ่น; ยังไม่ใช่การนำเข้าเกม |

## ข้อควรระวัง

- **มุมบนพื้นโลก ≠ มุมบนจอ** กล้อง arena เป็น oblique projection ที่ไม่คงมุม
  กรวย 90° ปรากฏเป็น ~73° (ชี้ East) ถึง ~107° (ชี้ North) — ต้องนิยามมุมใน
  พิกัดโลกแล้วปล่อยให้ projection จัดการ
- **ฐานตรงไม่ได้พิสูจน์มุมของวัตถุ** ตัวเอฟเฟกต์ยืนตรง ฐาน/ชายล่างแนบระนาบพื้น
  มีเพียง footprint ที่ผิดรูปตาม projection — ต้องตรวจมุมของตัวเอฟเฟกต์แยก
- ตาม [../map/README.md](../map/README.md) อย่ากำหนดองศาจาก screenshot หรือ
  คัดลอกค่าด้วยมือ ใช้ค่าที่ refresh จากโค้ดจริงเท่านั้น
