# Separate object or figure

Choose one subject and attach an appropriate style reference. A real camera render is preferable as a view reference when available; do not label an approximate generated view as exact.

```text
Create one isolated [SUBJECT] for a painterly fantasy tabletop map. Orthographic three-quarter overhead view, elevation [camera.elevationDegrees from hex-spec.json] degrees above horizontal. Use [EXPLICIT FACING DIRECTION OR APPROVED FACING REFERENCE]. Show enough top surface to read correctly from above. Match the project's muted colours, small readable forms and top-left lighting.

Transparent RGBA background. Include the whole subject with breathing room. Ground contact is [FEET / BOTTOM OF CHEST / BUILDING FOUNDATION]; keep this anchor unambiguous. No ground tile, scenery backdrop, display platform, circular base, outer shadow, border, text or UI. Target resolution [WIDTH] × [HEIGHT].
```

For mobs: communicate a hostile encounter, not a protagonist portrait. Weapons must make sense for the species; vampire and treant do not need handheld weapons. Preserve approved clothing and use the same agreed facing direction across the roster. If no facing reference has been approved, establish one first rather than inventing a different direction per image.
