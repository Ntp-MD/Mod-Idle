# Reusable VFX components

Use the [single raster shelf](outputs/README.md): named 2D shapes in 14 families, each usable with the seven runtime palettes. [Open the raster roster](outputs/index.html) for the current count and every raw/master pair. Update assets in place by shape name; the source guide owns the authoring policy. The earlier numbered production folders have been consolidated.

The raster roster adds 33 painted 2D still ingredients to the original 53-shape roster. Use the existing named PNG/raw/QA workflow and [exact prompts](outputs/generation-prompts.json). The owner deferred further 3D production on 2026-11-11. Earlier [3D sources](sources/README.md) and [animated experiments](outputs/animated/index.html) remain provenance; they do not count as new raster masters. Actor masking, sampled trails and optical distortion are future assembly work. New source art does not replace current runtime recipes.

Every live player skill has a flat skill recipe (90 total). The 49 mob skills are adoption gaps by design while mob skills are off. The 71 material-study recipes remain review candidates. Thunder Storm, auras and existing defaults were preserved; consolidation does not grant human visual approval.

## Assembly rules

- Copy ingredient PNGs into the existing skill's recipe directory; reference local filenames in `additionalLayers`. Keep each `layerId` unique, including repeated uses of one image.
- Ground ingredients use `projection: "ground"` and committed-footprint sizing. Directional line textures opt into `orient: true`; do not bake camera tilt into the source.
- Deferred 3D experiments declare `directional.presets`; they are outside the active 2D raster workflow. If reviewed later, select their camera/heading and preserve the rendered axes rather than projecting them again.
- Upright ingredients use body or authored world size. Bind roots explicitly to area, caster, target, contact or the existing release/socket point.
- Use `phases`, `delaySec` and `durationSec` for presentation timing. They do not create impacts, targets or damage.
- Optional `placement` supports `line-series` (spacingM, staggerSec), `line-front` (durationSec on the layer), `spin` (cycleSec), and `orbit` (cycleSec, radiusM). Offsets stay in world metres and reduced motion preserves contact/coverage.
- `tether` placement spans the sampled hand and target through the shared projection. It keeps authored world thickness, falls back to committed endpoints if an actor is missing, and hides coincident endpoints. `expand` uses `fromScale` in (0, 1] and layer `durationSec`; it scales around the stable root and shows final coverage in reduced motion.
- Horizontal cone material uses ground projection and `orient: true`. Upright wall segments remain screen-facing; their roots follow the committed line. Target/caster bindings use sampled actors when available. The dome is a translucent overlay; it does not implement a collision or 3D occlusion shell.
- Existing committed projectile, fan, volley, homing, chain, channel and rain producers remain authoritative. Do not invent duplicate gameplay trajectories or consume gameplay RNG.
- Additional layers do not inherit a parent rain or placement mode unless they declare it. Single-frame fragments stay inside their source frame.
- Follow the [raster authoring and registration guide](outputs/README.md) for current source work; the [3D proposal](spec.md) stays deferred. Source updates require no new numbered folder; human approval still governs runtime promotion.
