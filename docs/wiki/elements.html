Elements

Every Element names the status its hits leave. A Species resists its own Element; no Element counters another. An Element declared ahead of its content reads a dash until its status and its skill rows land.

Where an Element is resisted

Each Species owns one Element (`mob.species[].element`) and answers it at a flat `mob.species_res_pct` in every zone it lives in. Its Race does not set resistance. Every other Element lands on it unresisted.
