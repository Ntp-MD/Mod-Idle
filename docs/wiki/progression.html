Progression

XP to next level = kills at that level × XP per kill. Skill, field-skill and Mastery tracks use separate XP curves.

Level steps

XP to next = killsToLevel(L) × per_kill × min(L, mob_level_cap); kills at own level = XP to next / XP per kill. At the plateau, XP is fixed and mob XP still follows the level cap.

The passive tree

Every node holds one rank and opens from any owned neighbour; Start is free and every region opens from it. A Normal grants exactly +1 of its region's Core attribute for 1 tree point. A Notable grants its written profile of flat and percent lines for 3 tree points. A Keystone changes a mechanic for 1 attainment point and never spends tree points. treePoints = base 3 + 3 a level from 2–100 + 1 a level from 101–190 + claimed quest bonuses − spent tree; a Town task or Delivery offer carries a 10% chance of +1 tree point, rolled into the stored reward and paid only when the reward is actually claimed. Respec at a settlement is free and hands both wallets back at the prices the spec charged. The tree is a new character's: an older character is refused with its own message rather than rewritten.

The Keystones

Each Keystone is bought with attainment and may be held with any other except the pairs below. The same text is on the board when a node is selected.
