# Glossary

> [index](../index.md)

คำที่ในเอกสารนี้ **หมายถึง** · ถ้าคำไหนแปลว่ามันหมายถึง 2 อย่าง ให้ถือว่ายังไม่นิ่ม

---

## ⚠️ คำที่เคยใช้ผิด — อย่าใช้ตามแบบเดิม

| คำ | ความหมายที่ถูก | ไม่ใช่ |
|---|---|---|
| **drop chance** | โอกาสที่ของชิ้นหนึ่งจะดรอป เป็นเปอร์เซ็นต์ · มาจาก drop table · **B13 ไม่ได้แตะค่านี้** | ปริมาณของต่อชั่วโมง |
| **kph** | kills per hour · ตัวเลขเดียวที่วัดความเร็ว | ~~kph~~ ชื่อเดิมที่ใช้ผิด |
| **more** / **better** | more = เยอะขึ้นของชั้นเดิม · better = ของชั้นสูงขึ้น | ใช้ปนกันไม่ได้ |
| **defensive** | ทำให้ **clear โซนได้** ไม่ใช่ลดดาเมจขาเข้า | คำนี้เคยถูกใช้แปลว่า mitigation ซึ่งค่าจริงเป็นศูนย์ |

## Damage — ลำดับการคิด (ตกลงแล้ว)

```
1. eva → คำนวณก่อน · ถ้าหลบได้ hit นี้จบ ไม่มีดาเมจ
2. def → คำนวณหลัง · ลดดาเมจที่เหลือก่อนเข้าเลือด
```

→ `eva-pen` ต้องอยู่**ก่อน eva** และ `def-pen` ต้องอยู่**ก่อน def** · ตรงกับขั้นตอนใน [damage-pipeline](../03-gameplay/combat/damage-pipeline.md)

## Combat

| คำ | หมายถึง |
|---|---|
| **hit** | การโจมตี 1 ครั้ง ต่อให้โดนหรือไม่ก็นับ |
| **maxHit** | ดาเมจสูงสุดต่อ hit หนึ่งครั้ง |
| **interval** | เวลาระหว่าง hit สองครั้ง · ยิงถี่ = เวลาน้อย |
| **APS** | attack per second · ตัวเลขเดียวของความถี่ |
| **tempo** | ความเร็วรวม · interval + เวลาที่ต้องฟื้นจากการถูกผลัก · **คำนี้ไม่ใช่การลบดาเมจ** |
| **push** | สิ่งที่ mob ทำให้คุณช้าลง · เป็นอีกชื่อหนึ่งของ tempo ในทางกลับกัน |
| **crit** | critical strike · ครั้งที่โดนแล้วดาเมจทะลุ · **ยังไม่มีแกนและยังไม่มีที่ในสูตร** |
| **proc** | ทริกเกอร์ที่ทำงานเป็นครั้งเป็นคราว ไม่ใช่ทุก hit |
| **ICD** | internal cooldown · เวลาที่ trigger ต้องรอก่อนยิงซ้ำ |

## Damage

| คำ | หมายถึง |
|---|---|
| **additive** | ดาเมจที่บวกเข้าไปใน pool เดียว · ยุบเป็น DPS เดียว · **มีเพดาน 25% และเพดานจำนวน slot** |
| **conditional** | ดาเมจที่มีเงื่อนไข · เช่น pen ใช้ได้เฉพาะโซนเกราะ · **ไม่ยุบ ไม่มีเพดาน** |
| **additive pool** | กลุ่ม slot ที่แชร์เงินงบ 25% ด้วยกัน |
| **DR** | damage reduction · สูตร `A / (A + 5·D)` · เพดาน 90% |
| **pen** | การเจาะเกราะ มีสองชนิด: `def-pen` (ลด armour) · `eva-pen` (ลด evasion) |
| **window** | ช่วงเวลาสั้นที่มอบโบกได้ · เช่น gate แตก · **ต้องผูกกับแกนหนึ่งแกนเสมอ** |
| **window kind** | ชนิดของ window · แต่ละชนิดขยายแกนเดียว |

## Content

| คำ | หมายถึง |
|---|---|
| **layer** | มิติเนื้อหา 1 ชั้น เช่น armour hit-size · ตอนนี้มี 9 |
| **axis** | แกน core stat · ตอนนี้มี 4 · **ยังไม่ตัดสินว่าจะเหลือกี่** |
| **tag** | ป้ายที่ติดกับ zone หรือมอนสเตอร์ เช่น evasion สูง |
| **polarity** | ป้ายบอกว่า tag นั้น **ลงโทษ** หรือ **เปิดโอกาสให้** |
| **punish / amplify** | ฝั่งลงโทษ (ทำให้ build ผิดแย่ลง) · ฝั่งเปิดโอกาส (build ถูกพุ่ง) · **ทุก zone ต้องมีทั้งสองฝั่ง** |
| **niche** | build ที่ชนะที่ผิดโซน · ถ้าไม่มี zone ไหนที่ชนะเลย = ไม่มี niche |
| **cliff** | ความแย่ลงเมื่อเลือกผิด · วัดเป็นเปอร์เซ็นต์ที่ความเร็วลด |
| **idle-safe** | โซนที่ปลอดภัยเวลานอน · เล่น ~90% ของเวลา · cliff ไม่เกิน −20% |
| **contract tier** | โซนที่ผู้เล่น **เลือกเอง** ตอนตื่น · cliff ได้ถึง −60% |
| **base stat** | ตัวเลขประจำโซนที่ทำให้ build ผิดแย่ลง · **พูดกันสับสนเสมอ เพราะคำเดียวกับ base type ของอาวุธ** |

## Loot

| คำ | หมายถึง |
|---|---|
| **clear rate** | kph ÷ threshold ของโซน · เกิน 1 = ผ่าน · **ชื่อนี้ยังไม่นิ่ม รอคุณตั้ง** |
| **threshold** | ตัวเลขที่โซนนั้นต้องการ · ตอนนี้ใช้ 80% ของ optimum ในการปลดล็อก |
| **line** | บรรทัด affix หนึ่งบรรทัด |
| **rarity** | common / rare / epic / unique · **ยังไม่ตัดสินว่าเกี่ยวกับจำนวนบรรทัดยังไง** |
| **tier** | ระดับความแรงของ affix 1-5 · **ยังไม่ตัดสินว่า tier 1 คือแข็งสุดหรืออ่อนสุด** |
| **implicit** | สถิติที่ติดมากับฐานอาวุธ ไม่ใช่ affix ที่ roll |
| **smart drop** | ของที่ดรอปตรงกับ build ของผู้เล่น ~85% · ที่เหลือ 15% คือการพนัน |
| **auto-salvage** | แปลงของที่ใช้ไม่ได้เป็น currency อัตโนมัติ |
| **build signature** | `(tree flags + ฐานอาวุธ + แท็กของ)` · หน่วยเดียวที่ใช้คำนวณค่า |
| **perceptibility** | ผู้เล่น **รู้สึกได้** หรือไม่ว่าของเปลี่ยน · เพดานคือ ±9% |

## Project

| คำ | หมายถึง |
|---|---|
| **provenance** | ตัวเลขนี้มาจากไหน: วัด / อ้างอิงแหล่ง / ตั้งเอง / ความเห็น |
| **kph** | ชื่อเดิม · **เปลี่ยนเป็น `kph` ทั้งเอกสารแล้ว** |
| **measured-but-unverifiable** | เคยวัดได้ แต่สคริปต์ถูกลบแล้ว อ้างได้แต่ยืนยันซ้ำไม่ได้ |
| **kill criterion** | เงื่อนไขที่ถ้าผลเป็นแบบนั้น ให้ตัดทิ้งโดยไม่ต้องคิดใหม่ |
| **O1-O13** | คำถามที่ยังไม่ตอบ |
| **D1-D15** | สิ่งที่ตัดสินแล้ว |
| **R1-R4** | สิ่งที่หลักฐานล้ม |

## ที่ยังไม่นิ่มและต้องระวังเป็นพิเศษ

| คำ | ปัญหา |
|---|---|
| **base stat** กับ **base type** | คนละคำแต่ตัวอักษรเหมือนกัน · base stat = ของ zone · base type = ของอาวุธ |
| **layer** กับ **dimension** | ใช้คำเดียวกันในเอกสาร · ตอนนี้รวมเป็นคำเดียวแล้ว (layer) |
| **kill criterion** กับ **kill** | คนละเรื่องกันโดยสิ้นเชิง · ไม่มีที่ไหนต้องฆ่าอะไรในเกมนี้ |
| **more / better loot** | ห้ามใช้ปนกัน · ดูหัวข้อคำที่ใช้ผิดด้านบน |
