Stats and caps

Seven Core stats, and every point is yours to spend. Some lines stop at a cap — the table says which ones, and whether a real build can reach it.

Every stat also has one utility line, so no point is wasted. The last column is what a single point buys: every stat line is Base + K_core through the one K table (engine.json K), and the attack-speed and drop figures are already in the units the game adds them in.
