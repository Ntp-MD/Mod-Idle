# Selected 1x1 Icon Sources

Selected assets are copied from `art/1x1/<artist>/<icon>.svg` into the matching icon category. Non-gear alternatives use `1x1-<artist>-<icon>.svg`; each gear icon replaces its former artwork at the established filename. The table records the source mapping for replaced gear files. The skills icon folder is intentionally excluded.
